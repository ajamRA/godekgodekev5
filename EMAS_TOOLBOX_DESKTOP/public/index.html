Stealth Mode — Remote Toggle

These PC buttons send ADB commands to service_mode.sh already installed on the IHU. They change the car’s mode; they do not install the mod and are not PC-only settings.

Enable: hides modded apps, restores factory AVAS and stops custom daemons; persists after reboot. Disable: restores normal mod operation. Requires the service-mode script on the car.

Steering Controls — Install & Manage

The controller runs on the IHU, not on your PC. One controller provides Drive Mode, regen and the Stealth shortcut.

Install controller on IHU

Copies the controller and scripts to the car, registers auto-start and starts the daemon. Use this for initial setup.

Start / stop installed controller

Start runs the files already on the IHU; it does not install them. Stop ends the running daemon without uninstalling it or removing auto-start.

Shortcuts: hold Right 800 ms → Drive Mode; Left 800 ms → regen; Volume Down 5 s → Stealth. When stopped, buttons return to their normal volume function.
